## 🇬🇧 English Documentation

Mahdi-Digistore is a responsive, single-page E-Commerce web application inspired by Digikala (Iran's largest online marketplace). Built purely with HTML5, Tailwind CSS, and Vanilla JavaScript, it features a complete shopping workflow alongside a built-in, no-code Admin Dashboard.

### ✨ Key Features

- 🎛️ Built-in Admin Dashboard (No-Code Management):
  - Add new products with custom categories, images, and discount percentages.
  - Real-time price and discount editing for existing inventory.
  - Dynamic store brand name customization.
  - Order management panel to view customer purchases and tracking codes.
- 🔥 Amazing Offers Slider: Featured promotional section with a live countdown timer.
- 🔍 Instant Search & Smart Filtering: Live search bar, category filtering, and multi-criteria sorting (Most Popular, Cheapest, Most Expensive, Highest Discount).
- 🛍️ Slide-Over Shopping Cart & Coupon System:
  - Interactive cart drawer with quantity controls.
  - Automatic calculation of net savings and discounts.
  - Promo code support (Test code: DIGI20 for 20% off).
- 💳 Simulated Payment Gateway: Complete checkout modal capturing recipient details and generating unique order tracking IDs.
- 💾 Persistent LocalStorage State: Preserves cart items, submitted orders, and admin customizations across browser sessions.

# 🛒 دیجی‌استور (Mahdi-Digistore) | فروشگاه اینترنتی مدرن

یک وب‌اپلیکیشن فروشگاهی واکنش‌گرا (Responsive) با الهام از طراحی و امکانات دیجی‌کالا که به صورت یکپارچه با HTML5، Tailwind CSS و JavaScript خالص پیاده‌سازی شده است.

---

## ✨ امکانات و ویژگی‌ها

- 🎛️ پنل مدیریت اختصاصی (بدون نیاز به کدنویسی):
  - افزودن کالای جدید به همراه دسته‌بندی، تصویر و درصد تخفیف
  - ویرایش آنی قیمت و تخفیف کالاهای موجود
  - تغییر نام برند فروشگاه به صورت زنده
  - مشاهده لیست سفارش‌های ثبت‌شده توسط مشتریان
- 🔥 بخش پیشنهاد شگفت‌انگیز: اسلایدر محصولات ویژه به همراه تایمر معکوس زنده و اعداد فارسی
- 🔍 جستجو و فیلتر پیشرفته: جستجوی آنی نام کالا، فیلتر بر اساس دسته‌بندی و مرتب‌سازی (ارزان‌ترین، گران‌ترین، پرفروش‌ترین و بیشترین تخفیف)
- 🛍️ سبد خرید هوشمند و کد تخفیف:
  - دراور کشویی سبد خرید با قابلیت تغییر تعداد اقلام
  - محاسبه خودکار سود مشتری از تخفیف‌ها
  - پشتیبانی از کد تخفیف ۲۰ درصدی (DIGI20)
- 💳 شبیه‌ساز درگاه پرداخت بانکی: فرم تسویه‌حساب، ثبت آدرس مشتری و صدور کد رهگیری سفارش
- **💾 ذخیره‌سازی دائمی در مرورگر (LocalStorage):** حفظ اطلاعات سبد خرید، سفارش‌ها و تغییرات پنل مدیریت پس از بستن یا رفرش صفحه

## 🛠️ تکنولوژی‌های استفاده‌شده

- HTML5

- Vazirmatn Font (فونت فارسی وزیرمتن)
- FontAwesome Icons
